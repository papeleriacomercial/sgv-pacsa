# Archivos de datos, fuera del repositorio

Aquí van las exportaciones que se usan una vez para cargar o comparar: el
archivo de cuentas de Badger, muestras de Zoho, listados que manda la oficina.

**Nada de esta carpeta entra a Git.** Son datos de clientes reales —nombres,
direcciones, teléfonos— y el repositorio no es el lugar para eso. `.gitignore`
cubre la carpeta entera menos este archivo.

Los programas que los leen viven en `scripts/`.
